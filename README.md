#  AmanScan - 文件关键词扫描报告器与编码实验室

>  一个轻量级、免安装、纯 Python 编写的桌面级自动化小工具。

本项目最初只是一个初学者练手的自动化脚本，随着不断迭代，现已进化为一款完整的桌面软件。它不仅能递归扫描整个文件夹（支持 txt/docx/pptx 等格式），精准统计关键词出现的次数与行号并生成 Markdown 报告，还内置了一个极客感十足的“自定义二进制编码实验室”。

>  **核心设计哲学**：只读扫描、预览优先、绝不修改原文件。UI 多线程防卡死，所有异常优雅降级。

## 核心特性

-  **多格式深度解析**：原生支持 `.txt` / `.md` / `.csv`，并扩展支持 `.docx` / `.pptx` 格式的内部文本提取。
-  **多线程系统级 UI**：基于 `tkinter` 构建，扫描任务在后台线程运行，界面丝滑不卡顿，实时滚动输出日志。
-  **绝对安全的只读模式**：全程以只读模式打开文件，绝不修改、移动或删除你的任何原文件。
-  **二进制嗅探防伪装**：能自动识别并跳过伪装成文本的二进制文件（含 `\x00`）。
-  **极客专属编码玩具**：内置基于位运算的自定义十六进制编码/解码功能（注：仅为学习编码原理，绝非安全加密）。
-  **开箱即用的 EXE 体验**：已通过 PyInstaller 完美打包为单文件免安装程序，无需配置 Python 环境即可运行。
-  **优雅的 Markdown 报告**：自动生成带时间戳的详细报告，包含关键词统计、命中行号、跳过文件原因等。

##  如何运行

###  方式一：直接使用（推荐）
前往本仓库的 Releases 页面，下载最新的 `AmanScan.exe` 双击即可运行，无需安装 Python 或任何依赖。

###  方式二：从源码运行
如果你需要运行源码，请确保电脑已安装 Python（推荐 3.8 以上版本）。在终端依次执行以下命令：

1. 克隆仓库并进入目录：
   ```bash
   git clone 你的仓库地址
   cd Agent_v0.5

2.安装第三方依赖（如果要扫描 Word/PPT 必须安装）：

bash
pip install -r requirements.txt

3.启动 UI 界面：

bash
python main.py
